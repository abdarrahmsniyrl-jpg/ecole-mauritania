# 🏫 مدرسة موريتانيا للإلكترونية

**منارة العلم.. أصالة الشناقطة برؤية رقمية**

## 📋 نظرة عامة

منصة مدرسية موريتانية متكاملة تجمع 5 أدوار رئيسية:
- 👑 صاحب المنصة
- 🎯 المدير
- 👨‍🏫 الأستاذ
- 📚 التلميذ
- 👨‍👩‍👧 ولي الأمر

## ✨ الميزات الرئيسية

✅ إدارة المدارس والتلاميذ والأساتذة
✅ نظام حضور وغياب ذكي
✅ إدارة النتائج والدرجات
✅ حاسبة معدل تلقائية
✅ دعم العمل بلا إنترنت (Offline)
✅ مزامنة تلقائية آمنة
✅ نظام SMS والإشعارات
✅ مركز الدراسة والكتب
✅ إدارة الأقساط
✅ واجهة عربية RTL كاملة
✅ وضع نهاري وليلي

## 🛠️ التكنولوجيا المستخدمة

- **Backend**: Node.js + Express.js
- **Database**: MongoDB
- **Authentication**: JWT
- **Frontend**: React + React Router
- **Styling**: Tailwind CSS
- **State Management**: Redux
- **Database Sync**: IndexedDB (Offline)

## 🚀 البدء السريع

### المتطلبات
- Node.js v16+
- MongoDB
- npm أو yarn

### التثبيت

```bash
git clone https://github.com/abdarrahmsniyrl-jpg/ecole-mauritania.git
cd ecole-mauritania
npm install
```

### الإعدادات

```bash
cp .env.example .env
# ثم عدّل الملف بحسب إعداداتك
```

### التطوير

```bash
npm run dev
```

التطبيق سيكون متاح على: `http://localhost:5000`
