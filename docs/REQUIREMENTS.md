# متطلبات تطبيق مدرسة موريتانيا للإلكترونية

## 📱 نظام تسجيل الدخول المعدل

### بيانات الدخول
- **رقم الهاتف**: 8 أرقام موريتانية (مثال: 22222222)
- **كلمة المرور**: 6 أرقام (مثال: 123456)

### المصادقة
- استخدام JWT Tokens
- صلاحية التوكن: 7 أيام
- تشفير كلمات المرور

## 👥 الأدوار الخمسة

### 1️⃣ صاحب المنصة (Platform Owner)
- إدارة المدارس المشتركة
- إدارة الاشتراكات والباقات
- متابعة الإحصائيات العامة
- إدارة المحتوى التعليمي
- إدارة خدمة SMS

### 2️⃣ المدير (Administrator)
- إدارة مدرسته فقط
- إدارة التلاميذ والأساتذة
- إنشاء الأقسام والمواد
- إدارة الحضور والنتائج
- إدارة الأقساط

### 3️⃣ الأستاذ (Teacher)
- رؤية حصصه فقط
- تسجيل الحضور والغياب
- إضافة الدروس والواجبات
- إدخال الدرجات
- العمل بدون إنترنت

### 4️⃣ التلميذ (Student)
- عرض البرنامج الدراسي
- متابعة النتائج
- الوصول إلى الكتب والدروس
- متابعة الواجبات
- حساب معدله

### 5️⃣ ولي الأمر (Parent)
- متابعة أبنائه
- عرض الحضور والنتائج
- استقبال الإشعارات
- متابعة الأقساط

## 🌐 اللغات والواجهات

- العربية (RTL) - الافتراضية
- الفرنسية
- الإنجليزية
- وضع نهاري وليلي

## 🔧 التقنيات المس��خدمة

- **Backend**: Node.js + Express.js + MongoDB
- **Frontend**: React + Tailwind CSS
- **Authentication**: JWT
- **Offline**: IndexedDB
- **Validation**: Validator.js
- **Security**: bcryptjs
